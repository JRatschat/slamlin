# Slamlin

Slamlin is a point-trick duel for two with handicap offers, hidden second cards, and a three-card lay-off.

👉 View the game on BoardGameGeek:  
https://boardgamegeek.com/boardgame/481943/slamlin

Designer Diary: https://boardgamegeek.com/blog/16873/blogpost/192401/slamlin-my-first-trick-taking-design

## Repository Contents

This repository contains:
- The official **rules** (which include the game board and the token cards for print & play)
- A playingcards.io file for playing the game online
